Which browsers are supported on Mac?

TabLinker imports and restores tabs from 13 browsers on Mac:

  • Safari
  • Chrome
  • Edge
  • Brave
  • Arc
  • Vivaldi
  • Opera
  • Opera GX
  • Dia
  • Helium
  • Yandex
  • Decentr
  • Wavebox

Firefox is not supported. Firefox does not expose its open tabs to macOS automation, so TabLinker cannot read them. You can still add Firefox links to TabLinker manually, or by importing an exported bookmarks file.

The first time you import from a browser, macOS asks you to allow TabLinker to control it. If you declined, you can re-enable it in System Settings → Privacy & Security → Automation.
