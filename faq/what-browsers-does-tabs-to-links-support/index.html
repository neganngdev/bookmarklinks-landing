What browsers does Tabs to Links support?

Tabs to Links is now called TabLinker. It turns the tabs you have open into a saved list of links, and it works with 13 browsers on Mac:

  • Safari
  • Chrome
  • Edge
  • Brave
  • Arc
  • Vivaldi
  • Opera
  • Opera GX
  • Dia
  • Helium
  • Yandex
  • Decentr
  • Wavebox

Firefox is not supported, because it does not expose its open tabs to macOS automation.

On iPhone and iPad, you can save links from any browser using the Share Sheet or the TabLinker Safari extension.
