Does TabLinker auto-save sessions?

Not on a schedule. TabLinker saves when you ask it to, so you stay in control of what becomes a saved session and what it is called.

Saving is quick: on Mac you can capture every open tab in one click, or grab just the current tab with a keyboard shortcut. If you import from a browser with several windows open, TabLinker can create a separate folder for each window automatically.

Once something is saved it is written to your library immediately and synced to your other devices over iCloud, so there is no save button to forget.
