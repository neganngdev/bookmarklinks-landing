Which browsers are supported on Mac?

TabLinker imports and restores tabs from 14 browsers on Mac:

  • Safari
  • Chrome
  • Firefox
  • Edge
  • Brave
  • Arc
  • Vivaldi
  • Opera
  • Opera GX
  • Dia
  • Helium
  • Yandex
  • Decentr
  • Wavebox

None of them needs an extension or add-on.

Firefox works from TabLinker 2.5: import its open tabs, back them up with Auto-Backup, and save the current tab with ⌃⌥⌘T. There's no Firefox add-on to install. Firefox can't be controlled by macOS automation, so TabLinker reads the list of open tabs that Firefox already saves on your Mac instead. The first time, TabLinker asks you to allow access to the Firefox folder. It takes one click, and TabLinker only reads it.

A few things work differently in Firefox:

  • Firefox saves its list of open tabs on a short delay, so a page you just opened can take up to 30 seconds to show up.
  • Firefox starts switched off in Auto-Backup. Turn it on in Settings › Auto-Backup.
  • Private windows are never included.
  • TabLinker can't close Firefox tabs after saving them, and a session with several Firefox windows restores as tabs in the front window.

For the other browsers, macOS asks you to allow TabLinker to control the browser the first time you import from it. If you declined, you can re-enable it in System Settings → Privacy & Security → Automation.
